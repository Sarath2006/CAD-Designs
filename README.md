# Mechanical 3D CAD Models

## Overview
This project showcases a collection of 3D mechanical components designed using AutoCAD for educational and engineering purposes. The models are created based on standard engineering drawings, focusing on dimensional accuracy, mechanical design, and component visualization.

## Components Included

### 1. Mechanical Clamping and Shaft Guide
- 3D model of a mechanical clamping component.
- Designed for shaft guiding, support, and fixture applications.
- Includes mounting holes and a central clamping bore.

### 2. M12 Hex Bolt
- 3D model of an M12 hexagonal bolt with a 40 mm length.
- Features modeled external threads.
- Suitable for mechanical assemblies and engineering visualization.

### 3. M12 Hex Nut
- 3D model of a standard M12 hexagonal nut.
- Designed with a 10 mm height and 19 mm across flats.
- Suitable for bolted joints and mechanical assemblies.

## Tools and Technologies
- **AutoCAD 3D** – Mechanical component modeling and design.
- **CAD File Formats** – DWG, SAT, IGES, STL, STEP, and other formats where available.

## Applications
- Mechanical assembly design
- Industrial fixtures and shaft support systems
- Fastener and bolted-joint modeling
- Engineering drawing practice
- 3D visualization and CAD portfolio development

## Purpose
The objective of this project is to develop practical skills in 3D mechanical modeling, engineering drawing interpretation, dimensional accuracy, and mechanical component design.

## Note
These models are intended for educational and design demonstration purposes. File formats and model features may vary by component.
